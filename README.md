# おはツイ 画像受付フォーム

キーホルダー／缶バッジ用の画像を、購入者がスマホ／PCから簡単にアップロードできる受付フォームです。
`index.html` を Web に置くだけで動作します（画像の切り抜き調整はブラウザ内で完結）。

## 機能

- **商品タイプ選択**：キーホルダー または 缶バッジ
- **注文経路選択**：Booth（注文番号必須）／リアルイベント現地（注文番号不要）
- **キーホルダー**
  - **表面・裏面 2枚**の画像をそれぞれアップロード（両面とも必須）
  - **印刷方法（フチあり／ふちなし）を購入者が選択**でき、選択内容も送信されます
  - ドラッグ＆スライダーで仕上がりサイズ（縦向き 54×72mm）に合わせてトリミング調整
  - **完成見本を選択モードでリアルタイム表示**
  - 表・裏を 300dpi PNG（塗り足し込み）で書き出し、注文情報・印刷方法とともに送信
- **缶バッジ**
  - **片面のみ**（裏面アップロード不要）
  - 円形ステージで Ø58mm に合わせてトリミング（ドラッグ＆ズーム対応）
  - 300dpi の円形 PNG（約 685×685px、円外は透明）を書き出して送信
  - フチあり／なし設定は対象外（UI では非表示）

## セットアップ

1. `gas/コード.gs` の手順に従い Google Apps Script をウェブアプリとしてデプロイします
   （`productType` / `orderSource` と表面 `imageFront`／裏面 `imageBack` を受け取り Google Drive に保存します。缶バッジ時は裏面なしでも可。現地注文時は注文番号なしでも可）。
2. 発行された `/exec` URL を `index.html` 冒頭の `ENDPOINT_URL` に貼り付けます。
3. `index.html` を Web ホスティング（GitHub Pages 等）に置いて公開します。

## ファイル構成

- `index.html` — 受付フォーム本体（商品選択・画像選択・トリミング・完成見本・送信）
- `gas/コード.gs` — 送信先の Google Apps Script（Drive 保存・スプレッドシート記録）
